# בור-צלף

צלף אחד, נקודה קבועה למטה במרכז. עכבר מכוון, לחיצה יורה, רווח מחזיק נשימה.

מטרות יוצאות ממחילות וזזות. אחרות עומדות. חלקן מסיחים. שעון יורד. שמונה הריגות, או שהזמן נגמר, ובוחרים יכולת אחת מתוך חמש. לכל יכולת עשר רמות. עשרה רובים, ולכל אחד ירי אחר: מהירות, בעיטה, חדירה, הפחדה, או עיגול צר.
